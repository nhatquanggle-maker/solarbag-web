# Custom Fonts Directory for SolarBag

Place your font files here if you want to use local font files:
- `1FTV-VIP-Boring-Time.ttf` or `1FTV-VIP-Boring-Time.woff2` (Headline / Poster)
- `Junegull.ttf` (Local Vietnamese version if available)

The website will automatically load them via `@font-face` defined in `src/index.css`.
If not placed here, the website will use:
- Google Fonts `Baloo 2` & `Nunito` for headlines (100% full Vietnamese diacritics support)
- Google Fonts `Noto Serif` for subtitles and logotype
- Google Fonts `Nunito` for clean rounded body content
- Google Fonts `Mansalva` for handwritten annotations & notes
